# N-Link

Free, cross-platform, CX-II compatible computer linking program for the TI-Nspire

For usage instructions, see https://lights0123.com/n-link/

This fork builds with [Tauri 2](https://v2.tauri.app/) (WebKitGTK 4.1, as on Ubuntu 24.04 and later):
see [desktop/README.md](desktop/README.md) for how to build it.
